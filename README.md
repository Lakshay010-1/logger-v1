# Logger V1

A simple Node.js logging project demonstrating **EventEmitter**, file system operations, and system information using Node.js native modules.

## Features

- Event-driven logging using `EventEmitter`
- Logs application events to `details.txt`
- Records total and free system memory
- Adds timestamps to every log entry
- Periodically logs system memory every 2 seconds

## Tech Stack

- JavaScript
- Node.js

## Run Locally

```bash
node index.js
```

The logs will be appended to `details.txt`.
